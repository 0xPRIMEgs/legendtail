# Prompt: turn a loose request into a modeling brief

Copy or adapt the following task text. These are ordinary prompts, not installed commands.

> Read LEGENDTAIL.md and guides/01-brief-and-references.md. Turn my request and supplied references into a concrete asset brief. Identify the character's essential silhouette/proportion features, the target game view, geometry versus painted detail, texture budget, rig/export contract, and the evidence needed to review the result. Inspect existing project assets and loader conventions first. Resolve ordinary reversible choices yourself and state meaningful assumptions. Ask only for missing information that would materially change identity or compatibility. Preserve my requested scope. Then carry out the authorized modeling work, using the brief as the acceptance criteria.

Add the actual subject, references, budget, and target project after the prompt. If the user only wants prompt rewriting, replace the final sentence with “Return the improved brief/prompt without modifying assets.”

Useful constraint example: “Keep the blue elements visually under the armor; use real depth for the chest opening and explicitly label any painted approximation elsewhere.”
