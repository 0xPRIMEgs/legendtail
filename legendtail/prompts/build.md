# Prompt: build a constrained game character

> Use LEGENDTAIL.md for this asset. Inspect the supplied references and existing rig/loader. Build a recognizable character at the stated final triangle budget, including both mirrored sides and the specified accessories. Allocate triangles by silhouette and articulation; use textures for shallow surface detail. Preserve the verified part names, pivot frames, and attachment order. Check front, back, both sides, and a three-quarter view before finalizing. Export the requested engine files and portable model, re-open the output, and verify counts, materials, UVs, rig behavior, and package contents. Show renders from the actual model and report what was tested. Preserve editable source and textures in the handoff.

Add a filled [asset brief](../templates/asset-brief.md). Specify whether the budget is a hard cap or approximate target. Specify whether physical openings are required and whether weapon/effect geometry belongs in the character budget.

For several LODs, add: “Treat each LOD as an independently reviewed asset. Preserve the intended rig interface, and report the actual exported count and visual tradeoffs for every level.”
